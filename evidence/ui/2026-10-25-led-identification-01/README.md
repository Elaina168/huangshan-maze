## 结论与纠正

用户所指常亮绿灯的位置对应供电指示灯，不是PA32控制的RGB。照片支持RGB当时没有可见发光，因此“绿灯常亮证明RGB黑帧失败”这一诊断撤回；此前用户认为同一颗的口头判断由照片与官方标注澄清，不归咎用户。

不需要为了这颗供电指示灯继续修改RGB驱动或反复烧录；`maze_rgb_off`不能用来控制另一颗供电灯。当前`src/main.c`仍有将PA32_TIM与GPTIM2_CH1直接比较的误导诊断，这一已知代码问题与照片中供电灯常亮分开处理，未因本次照片宣称代码已修复。没有测量或承诺供电灯的电气控制方式，也未尝试关共享LDO。

本次只核对静态位置及照片可见状态，不把单张照片当作RGB所有颜色/时序测试通过，也不替代迷宫整体验收。
