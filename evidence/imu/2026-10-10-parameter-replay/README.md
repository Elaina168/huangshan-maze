# 校准与死区候选参数的离线回算

日期：2026-10-10。使用已有6组真机取样的analysis.json，未新增板端取样。首次neutral来自原附件，其余来自用户消息转录；来源文件与raw.log的SHA-256见[analysis.json](analysis.json)。首组left姿态待确认，继续排除。

方法是对归档数据进行候选参数算术回算，不运行板端新命令。均值采用C整数除法向零截断；屏幕横向取参考Y减原始Y，向下取原始X减参考X。

| 候选 | 值 | 已有数据的结果 |
|---|---|---|
| 稳定窗口 | 连续20点，跨度至少950ms，每轴范围≤300 raw，相邻间隔≤100ms | 两组neutral各21个滑动窗口均符合；跨度均969ms，最大XYZ范围分别27/27/64、32/44/69 |
| 逐轴死区 | 差值绝对值≤300输出0，超出后扣除300 | 分别使用初/末中立参考，对两组共80点处理均输出零；跨组差值峰值每轴最多110 raw |
| 四向可区分性 | 主要轴超出300 raw死区 | right/left重测/up/down所有点在两种参考下的最小余量分别7261/8568/6151/6530 raw |
| 输入年龄 | 超过100ms无效 | 未评估：归档日志没有实际消费者时间，51ms记录间隔不能证明输入年龄 |

滑动窗口相互重叠，21个窗口不等于21次独立真机校准。稳定倾斜也可以符合稳定窗口，它定义本轮舒适姿态参考，不证明姿态水平。范围与阈值不同：前者是观察结果，后者仍是待上板验证的候选。

本次没有验证持续晃动校准、实际消费年龄、触摸/可见运动延迟、球心漂移或运行实现。不能替代TC-002/003/004/005/014，也不能以此确认正式产品参数。用户已同意以这些候选实现下一轮串口预研，流程见[预研实施记录](../../../docs/research/imu-probe-plan.md)。
