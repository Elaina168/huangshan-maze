# 成绩页按来源返回修复

2026-11-03，REQ-052/053、TC-073/075，目标版本0.13.1-score-return。

用户指出查看成绩后还需重新选地图才能回准备页。实际main的随机成绩入口调用progress_leave/app_cancel，导航BACK又统一返回SELECT。此前仅说明“选关”按钮不能满足原页返回要求，本次修正行为。

最小设计见[说明](../../docs/superpowers/specs/2026-11-03-score-return-fix.md)。保留现有random_scores区分两个真实入口，无新增来源栈/字段/命令。随机成绩入口不结束挑战，BACK恢复GAME，按钮“返回”；选关进入固定成绩仍“返回选关”。不新增暂停页成绩入口，不改采样、物理、地图、存档格式或生成器版本。

- `main-red.log`：实际main外部I/O替身，断言进入成绩后app/progress保持，原代码失败。
- `main-green.log`：修改后进入/切换成绩模式/返回保持地图指针、种子、采样代次、挑战状态/时间/失误/修订，无额外保存；固定成绩返回选关、旧实际main流程与128B日志预算回归通过。
- `random-green.log`：真实导航READY/WON/LOST返回保持、随机地图/成绩/取消相关原回归通过。不是板端证据。
- `ui-random.log`、`ui-refresh.log`：实际SDK LVGL离屏，触摸“返回”恢复原随机结果，“返回选关”回SELECT，原固定成绩及界面回归。
- `random-scores.png`：实际离屏成绩页，“未保存”为既有测试注入，不是新设备故障。

中间测试曾把返回后主循环正常更新的last_update_tick也要求完全相同，断言失败；已核对maze_app_update末尾的现有时基更新，只允许该字段正常推进，其余app/progress保持逐字段字节一致。没有改动产品时基以迁就测试。

完整固件、源码/三产物哈希与下载目录见[构建记录](../builds/2026-11-03-score-return-01/README.md)。板端待新版“准备→本图成绩→返回”短测；未烧录或提交推送。无存储源码变化，不重复1045次受控中断。
