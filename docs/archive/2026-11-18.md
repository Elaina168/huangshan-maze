## 恢复完整本地快照

下载local-backup.zip和restore_backup.py，将目标目录设为一个新目录后执行。

```powershell
python restore_backup.py local-backup.zip D:\restore\huangshan-maze
```

快照按文件SHA-256保存内容，同内容文件共用一份数据。恢复脚本按清单还原每个文件与空目录，并检查每份内容的校验值。恢复后可在工程根目录运行git log --all、git fsck --full和python scripts/check_project.py。
