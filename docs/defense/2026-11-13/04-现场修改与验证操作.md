# 现场修改与验证

李天宇 · 2024211450 · 2026-11-13

## 展示目标

通过一个局部修改，说明配置或界面如何影响运行结果，并展示对应的验证流程。操作前保存当前版本，在工程副本中完成演示。

## 示例一　修改最大速度

最大速度由maze_config.h中的MAZE_SPEED_MAX定义，当前值为180.0f。maze_model_step合成二维速度后，用hypotf计算速度大小，再按上限统一缩放。[打开配置](../../../src/maze_config.h) · [查看物理入口](答辩演示.html#code-step)

讲解时可使用下面这段说明。

> 我把速度上限由180调整为200像素每秒。倾斜仍产生加速度，旧速度仍受地面阻力影响。模型在合成二维速度后执行限幅，因此这个修改会改变持续倾斜后的最高移动速度。

1. 将MAZE_SPEED_MAX从180.0f改为200.0f。
2. 检查inertia_harness.c中原180.001f上限断言，按新规格修改预期。[打开惯性用例](../../../tests/maze/inertia_harness.c)
3. 在已有C编译器的环境运行逻辑回归，检查加速、滑行、反向制动、墙角、高速碰撞和动态机关。

```powershell
python scripts/test_maze.py
python scripts/check_project.py
```

4. 在SDK已激活的终端运行构建脚本。

```powershell
python scripts/build_firmware.py
```

5. 查看build/build-state.json，核对returncode为0、source_unchanged为true和stage_path中的三项固件。[打开构建脚本](../../../scripts/build_firmware.py)
6. 关闭串口监视器，确认板卡与实际COM端口，使用本次构建的固件烧录。
7. 在同一关卡下持续倾斜，比较最高移动速度、制动和过弯表现，记录实际画面与串口输出。

## 示例二　修改选关标题

选关标题由maze_ui.c的界面分支设置。可把“体感迷宫”改成“体感迷宫演示”，说明触摸与渲染流程如何将文字呈现在屏幕上。[打开界面实现](../../../src/maze_ui.c)

1. 修改选关页标题字符串。
2. 更新stage7_ui_harness.c对应的标题断言。[打开界面用例](../../../tests/maze/stage7_ui_harness.c)
3. 使用实际SDK中的字体文件重新生成字形。以下参数中的SDK目录按本机安装位置填写。

```powershell
python scripts/generate_ui_font.py --font '<实际SDK目录>/external/lvgl_v9/tests/src/test_files/fonts/noto/NotoSansSC-Regular.ttf'
python scripts/check_project.py
```

4. 在已有主机C环境构建并运行真实LVGL目标ui-stage7和ui-refresh。目标定义见tests/maze/lvgl-host。[打开LVGL测试配置](../../../tests/maze/lvgl-host/CMakeLists.txt)
5. 执行完整固件构建、核对本次产物、烧录并观察标题与中文字形。

## 示例三　解释钥匙与门

打开机关试炼地图，找到link为0的钥匙与门，再查看模型中钥匙位图及门的判断。收集钥匙后，模型更新状态，后续碰撞与显示使用同一状态。[打开机关地图](../../../src/maze_map_mechanism_trial.c) · [查看机关模型](答辩演示.html#code-mech)

> 地图定义钥匙和门的关联编号。球触发钥匙后设置对应状态位，门的碰撞检查读取这个状态。界面根据模型状态同步更新钥匙和门的显示。

## 操作条件

- 中文工程路径通过build_firmware.py生成ASCII临时快照完成构建。
- 烧录工具使用本机已安装sftool.exe，串口号以设备当前状态为准。
- 校准需要20点、至少950ms跨度和每轴不超过300raw的稳定范围。
- 自动回归、SDK构建与板端观察分别记录各自结果。
