## 5. 稳定校准与倾斜输入

校准检测板卡在一个时间窗口内是否稳定，然后把三轴均值作为当前握姿的中立参考。正常显示方向是USB在右侧。当前水平输入来自第二轴与参考值的差，竖直输入来自第一轴的反向差，随后经过300raw死区。新局校准后进入游玩，暂停重校准和设备恢复成功后回到暂停。

- 采样包含generation、sequence、read_start_tick和error。
- 参考值取三轴平均，死区使中立附近输入归零。
- 反转模式对x、y同时取负。

## 6. 钢珠运动与三种地面

倾斜输入先换算成加速度，再与旧速度相加，并通过地面阻力更新速度。普通地面阻力为3，冰面为0.6，粗糙地面为9，所以同样的初速度在冰面上衰减更慢。位置由更新后的速度推进，二维速度最后统一限制到180像素每秒。

- 10ms物理步累计运动，动态机关场景继续细分。
- 放平后按阻力逐步减速，反向倾斜产生制动。
- 二维速度统一限幅，控制斜向运动的总速度。

```c
    float magnitude=hypotf(input_x,input_y);
    float scale=MAZE_ACCEL_MAX/fmaxf(MAZE_INPUT_FULL_RAW,magnitude);
    float dt=(float)dt_ms/1000;
    maze_surface_t surface=maze_level_surface_at(m->level,m->x,m->y);
    float drag=surface==MAZE_SURFACE_ICE?MAZE_DRAG_ICE:
        surface==MAZE_SURFACE_ROUGH?MAZE_DRAG_ROUGH:MAZE_DRAG_NORMAL;
    /* 输入施加加速度，隐式阻尼保留惯性；切换地面不直接重设速度。 */
    m->vx=(m->vx+input_x*scale*dt)/(1+drag*dt);
    m->vy=(m->vy+input_y*scale*dt)/(1+drag*dt);
    float speed=hypotf(m->vx,m->vy);
    if (speed>MAZE_SPEED_MAX)
    {
        m->vx*=MAZE_SPEED_MAX/speed;
        m->vy*=MAZE_SPEED_MAX/speed;
    }
    else if (magnitude==0 && speed<MAZE_STOP_SPEED) m->vx=m->vy=0;
    if (m->level->mechanism_count) { mechanism_motion(m,dt_ms); return; }
```

## 9. 状态机与挑战计时

计时分成当前运动段和整次挑战两个层次。app记录当前段，progress累计之前的段。这样暂停和校准等待时间被排除，而失败后继续同一关挑战时，之前有效游玩的时间仍计入成绩。通关后再重玩和离开关卡会按新挑战流程处理。

- 暂停冻结位置、速度和运动时间，继续使用有效采样恢复。
- 暂停重校准、设备错误恢复成功后回到暂停。
- 失败或暂停后的重玩重置当前段，保留同关挑战累计。
- 检查点复活恢复机关快照，再校准后开始新运动段。

## 公式演算补充

下面按一个10ms步推演普通地面的速度更新。输入4096对应加速度300像素/秒²，旧速度为60像素/秒，阻力系数为3。

```text
dt = 0.01秒
v1 = (60 + 300 × 0.01) / (1 + 3 × 0.01) = 61.1650像素/秒
下一步放平，输入归零
v2 = 61.1650 / (1 + 3 × 0.01) = 59.3835像素/秒
```

比较地面滑行时，统一从速度60、输入0开始。普通地面下一步为58.2524，冰面为59.6421。阻力越小，单步速度下降越少。

## 校准与计时问答

稳定校准将当前握姿作为中立参考，检测条件为样本数量、时间跨度和各轴波动范围。稳定倾斜的姿态也可建立参考。

app.elapsed_ms记录当前运动段，progress.accrued_ms累计前面的有效运动段。失败或暂停后重玩时，当前段清零，挑战累计由progress维护。通关后重玩和离开关卡按新挑战流程处理。

暂停重校准和设备恢复成功后进入PAUSED。检查点复活先恢复模型快照，再以MAZE_CAL_NEW重新校准，成功后进入PLAYING。
