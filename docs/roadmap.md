| 阶段 | 内容 | 完成条件 |
|---|---|---|
| 1 地图与参数基础 | 参数集中、二维数组/字符串+机关对象表、板端装载、静态合法性检查 | 现有冰岔迷宫改用新格式，布局/手感不变，数据与球半径几何检查可执行 |
| 2 多关卡与设置 | 选关、下一关、返回、切关重置、方向反转和模式标识 | 板上完成选关和切换，旧会话/事件不能影响新关 |
| 3 成绩与存档 | 解锁、失误次数、分关成绩/本地排行榜、独立Flash存档 | 正常重启保留数据，保存中断电的一致性有证据，预留实际需要的数据版本 |
| 4 基础机关 | 不同地面→钥匙/开关/门→可破坏墙→检查点复活 | 明确每种规则、复活/重玩状态及成绩计时，逐关验证 |
| 5 复杂机关 | 磁力/吸附→定时激光/闸门→移动障碍/巡逻块 | 施力、时序、相对碰撞及暂停恢复正确 |
| 6 板端随机地图 | 板上生成、检查几何与机关前置关系、限制规模/耗时 | 无需电脑工具即可生成可玩的受支持模板地图；无法生成时明确反馈 |
| 7 黑暗与视觉反馈 | 黑暗关卡、过关动画、失败闪烁、菜单过渡、RGB灯效 | 无阻塞、可取消，新增显示开销与板端体验有验证 |
| 8 看门狗与整合 | 按实际工作耗时监控真实健康状态、受控恢复及相关回归 | 不无条件喂狗、不掩盖既有错误，恢复行为有真实证据 |

地图合法性检查随机关逐步增强，不能只靠静态起终点连通证明带机关可通关。存档字段/版本随明确规则演进，成绩需区分不可比模式/随机地图。

产品使用仅依赖板子及供电。电脑用于开发、烧录和必要测试，不是用户功能的依赖；不制作电脑端地图生成/转换工具、不要求串口操控或联网。声音/蜂鸣/振动暂停，保留RGB；不加入传送门、弹跳板、自动或持久化校准等未选功能。旧B/C仍按用户要求停止，每阶段仅完成新增功能必要验证。
