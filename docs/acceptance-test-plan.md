# 黄山派体感迷宫：验收测试计划

版本：v0.2 计划，参数待预研。日期：2026-10-10。关联：[产品需求规格 v0.2](product-requirements.md)、[课程要求清单](course-requirements.md)。

本文为计划，所有用例均未执行。用户反馈的屏幕、触摸、IMU 正常属于外设示例的前期观察，不能填成迷宫验收通过。功能范围与玩法已确认，数值和技术参数仍需预研后同步本计划。

## 1. 方法与证据

- 纯逻辑：碰撞、区域判定、状态转换、时间累计和显示频率影响，用可重复的输入与断言自动验证。
- 板端：IMU 方向、校准、实际触摸、显示、控制响应、内存与任务资源、连续运行。
- 故障：主机可注入读失败/陈旧采样；板端采用明确标注的测试机制，不拔插带电内部传感器、不伪造硬件故障。报告区分逻辑注入与真实 I/O 证据。
- 每次结果记录：源码提交、固件校验值、板型、SDK/工具链、操作条件、步骤、输入、预期、实际、通过/失败/未执行、证据路径及关联问题。
- 失败记录不覆盖；修复后关联新提交追加重测，并执行相关回归。

## 2. 测试环境

目标平台：sf32lb52-lchspi-ulp，SiFli SDK v2.5.1，RT-Thread、LVGL v9。实际工程的版本、编译器、板卡标识、固件与构建配置在执行时记录，当前不编造。

主机测试构建方式和 SDK 资源测量接口由后续实际源码与环境确认。独立时钟或视频用于时间比较；没有相应仪器的性能项目保持未执行，不替换成主观“很流畅”。
