## 下一次小步实测：暂停及资源

关联REQ-007/008/010/012/013，TC-010/011，TC-013退出路径与资源准入。不改参数、不烧录、不要求重复胜败闭环。保持当前固件、USB右侧，串口持续留存日志。

1. 回到准备页，依次输入`free`、`ps`，保存为“操作前”。若本来就在游戏中，先Pause再Exit。
2. Start后保持稳定约1秒，成功后移动小球一小段，停在安全处。点Pause，记下屏幕用时和小球位置。
3. 暂停约10秒，期间轻微倾斜：观察小球和用时是否保持。点Resume，观察从原位置继续，暂停的10秒不补入；是否报错、是否突然跳动如实记录。
4. 再次Pause，放稳并点Calibrate。成功后应仍在暂停、位置和用时保留。明确点Resume后才继续。
5. Pause→Exit回准备，依次输入`free`、`ps`，保存为“操作后”。保留这段全部`[maze]`及如有的`[maze_timing]`输出。
