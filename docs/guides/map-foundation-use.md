# 0.7.0地图基础短测

这版不改变现有迷宫、操作和钢珠参数，只更换地图数据来源并增加板端检查。不是选关或随机地图版本。

启动先出现两行`[maze_map]`日志：第一行含result/check_ticks/workspace，第二行含id/walls/traps/ice/nodes。正常应result=0、id=frost_fork、walls=29、traps=3、ice=2；workspace来自目标固件sizeof，检查耗时由check_ticks及原日志tick_hz换算，不把主机耗时当板端耗时。

烧录后只需贴这两行，并确认仍看到原冰岔地图，开始校准后可移动、暂停/继续正常，手感与原版相同。此次不用重做A或已停止B/C。

若数据装载失败，屏幕会独立显示“地图载入失败”、原因与错误码，没有开始按钮；本轮仅支持复位后重新检查，不会偷偷切回旧地图。这些失败场景已通过受控输入和真实LVGL离屏验证，不需要为了试错误页烧录故意损坏的数据。

错误编号：-2001地图格式，-2002对象定义/数量，-2003几何位置/大小，-2004未找到静态安全路线。后者不表示连续空间数学上绝对无解，因为当前检查采用保守5px格点。

后续地图内容位于src/maze_map_frost_fork.c，公共参数位于src/maze_config.h；玩家游玩不需要电脑端地图工具。普通构建已有字体生成物可用，不必重新安装工具。开发阶段的主机测试仍保留。
