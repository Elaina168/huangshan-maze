# 中文版界面短测

新版0.6.1保持当前地图与钢珠参数，只替换显示文字并编入本界面所需中文字形；串口命令和日志字段保持原英文标识，便于对照已有记录。

烧录后确认标题“冰岔迷宫”，准备页提示USB在右侧。点“开始”后放稳，顶部显示“请放稳: 0/20”并更新实际稳定窗口计数；成功后自动进入“游玩中”，上方区分普通地面和冰面。暂停页按钮为“继续 / 校准 / 重玩 / 退出”，含义与原版相同。若重新校准失败，保留本轮并显示错误码；出现设备异常时按提示放稳重试，恢复后回暂停。

本轮只需确认中文无方框、乱码或截断，以及开始/暂停/继续可用。失败或胜利页遇到时顺便看文字，无需为了截图重做旧A或B/C。请反馈字是否清晰、字号是否合适；板端结果需真实反馈后记录，离屏图片不是实物截图。

## 再生成字体

已有完整源TTF来自SDK，哈希在[字形清单](../design/chinese-ui-font.json)。使用现有Pillow 12.3.0与UTF-8 Python执行`scripts/generate_ui_font.py --font <实际NotoSansSC-Regular.ttf路径>`，生成物已随工程保存，普通构建无需Pillow或原TTF。新增屏幕文案后需重建；`--check`可核对是否遗漏更新。许可和修改范围见[第三方清单](../../THIRD_PARTY.md)。
