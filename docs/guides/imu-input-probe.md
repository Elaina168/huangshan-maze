# 校准与控制输入预研

对应Task 3，支持REQ-002/003/011与TC-002/003/004/005/014的后续实现；本版还没有迷宫、小球、碰撞或计时。版本0.2.2-imu-input-probe，页面IMU INPUT PROBE，USB RIGHT。

## 操作一轮即可

1. USB在右、文字正向。点击CENTER启动校准，然后把板子放稳在舒适姿态；不用盯着快速原始日志。
2. 页面显示Calibrating与窗口数量。20点、窗口跨度至少950ms且三轴变化范围都不超过300 raw才成功；数字到20不单独等于成功。预算3秒，超时显示错误，不能一边明显晃动一边要求成功。
3. 出现Input ready且串口有calibrated ref后，再随意轻倾板子，查看页面x/y和每约500ms的xy日志变化。中立附近应为0；这些数值是经过死区的raw输入，不是角度或像素速度。
4. 再点CENTER停止，回Center: calibrate，x/y归零；可查询free、ps保留本版资源。提供开始、成功/失败、xy变化、停止及资源日志即可，不要求重复五轮或重采原始四向。

若校准失败，放稳后点CENTER重试；采样错误或过期会清零输入并停用后台，本轮不自动恢复，下次点击重新校准。无需拔插板载传感器制造错误。

## 日志解释

state数字：0准备，1校准，2输入就绪，3校准失败，4输入错误。

- error=-1003：3秒校准截止已到。
- error=-1001：样本读取起点至消费/检查时刻超过100ms。
- error=-1002：就绪后相邻读取起点间隔超过100ms。
- 其他非零错误保留后台I2C实际返回，不当作玩家失败。
- 校准时跳号或间隔过长会重新收集窗口；超龄样本被丢弃并清窗口，不延长原来的3秒预算。

USB右映射：x=rawY-referenceY，y=referenceX-rawX；逐轴绝对差≤300为0，越过后扣掉300。使用者旋转180°与旧实验的坐标关系已确认，不重复原始四向采集；实际小球方向留到运动接入时检查。

候选参数并非正式性能基线。显示数字刷新、有限日志成功都不能替代可见运动响应、静置球心漂移或长期资源验收。每轮校准重新采中立参考，旧参考只在本次校准成功时才替换。
