# 冰岔迷宫 0.6.0 操作说明

关联REQ-024、TC-028至030。屏幕正常方向为USB在右侧，保持0.5.1的钢珠参数：上限180 px/s、加速度600 px/s²，普通/冰面阻尼3.0/0.6。启动地图已从开放对比场换成固定迷宫；旧地图仍保存在源码中。

## 怎么玩

点Start后放稳，20个稳定样本校准成功再开始计时。轻倾加速，提前反向制动；放平仍会惯性滑行。红坑在必经通道的一侧，需绕开，不能靠选择另一分支避开全部陷阱；蓝色冰面更滑，绿色圆是终点。墙只阻挡，球心进入红坑才失败。暂停、重校准、重玩和退出沿用已有规则。

起点在左上，先向右进入第一个竖向通道，靠左绕第一个红坑。到地图下部后可沿底部绕普通地面长路，或进入中下部两格蓝色冰面走捷径；两路在中部汇合，再上行经过第二个红坑（靠左绕），经右上区域下行，第三个红坑靠右绕，最终到右下绿色终点。

路线图：[普通长路及冰面捷径](../design/maze-layout-2026-10-31/routes.png)。这是设计示意图，非实物截图。

## 本轮只做地图短测

烧录后确认标题FROST FORK、墙/红坑/蓝区与图一致。体验一次绕坑、分岔回头及冰区制动；能通关则记录是否走冰面，落坑也可直接Replay。留意暂停/继续是否正常，异常时保留前后日志。无需重做既有A或已停止的B/C。主机路线通过只能证明存在可达轨迹，不能代表人工操作难度已经合适。
