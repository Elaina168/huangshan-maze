# 三固定关与随机娱乐：使用及短测

版本 `0.14.0-three-and-casual`。菜单只保留：

1. 冰环迷宫：第一关，默认开放。
2. 机关试炼：冰环迷宫任一模式通关后解锁。
3. 动力机关：机关试炼任一模式通关后解锁。
4. 随机挑战：娱乐模式，不参与固定关解锁。

冰岔迷宫、冰弯迷宫源码与入口已删除。三固定关保留原成绩、正常/反转模式和排行榜；旧存档按稳定ID迁移，冰环作为新首关开放。

## 随机娱乐模式

- 板上生成600×500地图，镜头跟随小球；生成中可取消。取消换图保留原地图和原暂停状态。
- 保留普通/冰面/粗糙地面、可绕陷阱、检查点、钥匙/开关门及受支持的动态机关；按原规则胜败、复活、暂停和重玩。
- 没有本图成绩、排行榜、名次、失误统计或计时成绩；胜败不记录成绩。
- “重玩”仍是同一张图；“换一张地图”成功后才替换，失败/取消不换。
- 只保存当前种子与生成器版本，重启能重建同图；局内位置不保存。保存失败会提示未保存地图，可在准备页点“保存”重试。

## 存档升级

兼容读取v1至v5，只写524B v6。迁移保留三关记录和当前随机地图身份，取消两关与随机榜单不迁移。成功写v6后旧固件不能读取；不需要清档、整片擦除或额外电脑工具。

## 一轮短测（TC-077）

1. 确认菜单仅上述四入口，冰环开放；检查保留三关的旧成绩/解锁。成绩页应只循环三关，“返回选关”回菜单。
2. 进入冰环开始校准，移动/暂停/继续正常；任选当前已解锁的另一个固定关确认可进入。
3. 进入随机挑战，确认没有本图成绩/失误/计时榜；失败、复活或重玩、通关后仍只显示娱乐反馈。
4. 随机暂停时换图并取消，确认原地图可继续；再换图完成，记录新种子。正常重启后应重建该图，三关旧成绩保留。
5. 观察滚动无闪球/黑块、无设备异常，回菜单后贴一次`free`、`ps`与启动/异常附近日志即可。不恢复旧B/C，不要求已测内容全部重跑。

软件、受控中断和离屏结果不代替本轮板端反馈。
