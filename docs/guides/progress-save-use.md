# 0.9.0成绩、解锁和存档新增短测

本版首次运行只开放冰岔迷宫，冰弯显示未解锁；0.8.0没有历史存档，不把之前通过自动记为解锁或成绩。产品运行只需板子及供电，以下串口日志仅供研发验证。

先关闭串口监视器释放实际端口，再按本版构建目录烧录默认bootloader/main/ftab三项。不要整片擦除，不要写入0x12DB0000至0x12DC0000的游戏档案区。若实际端口仍是COM6，执行：

```powershell
Set-Location 'C:\Users\zytx\AppData\Local\Temp\huangshan-maze-wgrc2ra3\project\build_sf32lb52-lchspi-ulp_hcpu'
& 'D:\sifli\tools\tools\sftool\0.2.5\sftool.exe' -p COM6 -c SF32LB52 -m nor write_flash 'bootloader\bootloader.bin@0x12010000' 'main.bin@0x12020000' 'ftab\ftab.bin@0x12000000'
```

启动标识`v0.9.0-progress-save`，main.bin609108B，SHA-256 `f1950f202e00c21982d3ef6e519c7d5c3114839fa133af14b85aebcbe30dbf5b`。[完整构建记录](../../evidence/builds/2026-11-01-progress-save-01/README.md)。

一次检查以下新增路径：

1. 上电看到第一关开放、第二关未解锁。点击成绩，确认两关两模式均无记录；返回，不必重新做旧方向/墙边批次。
2. 正常模式第一关开始，落坑一次后重玩，确认失误变1，挑战用时继续累计。通关后应有本次成绩/排名及保存反馈，第二关解锁，下一关进入准备而非自动运动。
3. 回选关查看第一关正常模式记录与累计失误；反转模式应没有混入正常成绩。反转模式第一关落坑一次后退出，再查累计失误，确认只增加反转项，未通关不入榜。
4. 等保存提示结束，重新上电。确认第二关仍解锁、正常榜及两模式累计失误保留，方向默认正常；不要求重复通关两关。
5. 如遇“未保存”，结果或选关页点保存重试；**错误未清除时断电可能回到上次已保存进度**。不要为了制造故障而拔插内部传感器。保留错误码及是否恢复的实际结果。

留存`[maze_store] open/save`的result、ticks、active、revision及启动tick_hz，计算实际读写耗时；初始准备及上述操作结束准备态各取一次free/ps即可，不恢复旧B/C长测。若不方便贴日志，可先反馈可见行为，但量化数据仍保持待证。

正常保存后重启支持“已保存数据能读取”，不等同于保存中真实断电验证。主机已有FlashDB故障注入也不冒充真实板端掉电。首次建库中断没有有效档案时可能保持存档错误页，重试只重新探测，不承诺必能自动修复，不自行擦除未知数据。
