# 最终界面使用检查

当前程序版本`0.16.1-ui-trim`，本轮修改按用户明确清单完成；最终版本于2026-11-07确认，材料修订使用v0.16.1-docs.1。

## 本轮变化

- 选关标题改为“体感迷宫”，删除USB/轻倾提示及底部选关校准提示。
- 关卡准备页只显示“准备就绪”，删除USB方向文字。
- 游玩顶栏不显示地面名称、钥匙/开关计数，保留状态、检查点或本局失误提示。
- 随机标题隐藏生成器版本，保留种子、模式及未保存提示。
- 固定关成绩页删除累计失误，保留每条成绩的玩法与本次失误，以及原来的排序/五条容量。
- 删除仅用于以上展示的控件、地面缓存/查询与计数循环；中文字体裁剪为226字形、27135字节位图。

关卡地图、机关交互、地面摩擦、档案v7、单局失误排序和看门狗参数沿用原规则。准备页的玩法说明仍用于指引。

## 一轮复测

启动应为`v0.16.1-ui-trim`。检查选关页标题和删除项，进入三固定关检查准备/游玩顶栏，查看每关成绩页；随机标题应没有v1，仍能区分种子与玩法。正常移动、暂停、检查点/机关、保存和返回操作一起顺手确认即可。遇到问题贴所在页面、操作步骤及相关日志。

界面自动检查结果见本轮证据，板端操作可按本页步骤复核；看门狗和资源专项测量方法见[第8阶段说明](stage8-use.md)。

完整路径、三固件SHA和资源见[构建记录](../../evidence/builds/2026-11-07-ui-trim-01/README.md)。


确认板卡串口并关闭串口监视器；若仍为COM6：

```powershell
Set-Location 'C:\Users\zytx\AppData\Local\Temp\huangshan-maze-s0fru_k2\project\build_sf32lb52-lchspi-ulp_hcpu'
& 'D:\sifli\tools\tools\sftool\0.2.5\sftool.exe' -p COM6 -c SF32LB52 -m nor write_flash 'bootloader\bootloader.bin@0x12010000' 'main.bin@0x12020000' 'ftab\ftab.bin@0x12000000'
```

重新连接串口后检查启动版本，再按上述清单完整复测。下载保留原有存档分区。
