## 只比较这次新手感

Start后保持舒适中立姿态，校准成功再倾斜。沿用已有Pause/Resume/Calibrate/Replay/Exit，不要求重做整套A或已停止的B/C。

1. 普通区轻倾使球滚动，再回到校准时的中立姿态，应继续滑一小段再停。反向倾斜应先减旧速度，再反向。
2. 滚动时改为横向倾斜，应沿弧线转向。普通区应比较容易刹住；这里的“放平”是回到校准参考，不一定严格水平。
3. 进入右侧ICE后用相近初速重复中立/反向操作，观察是否滑得更远、是否需要更早刹车。顶部标签应在球心跨过分界时切换，不按球边缘；来回跨区不应突然停住或瞬间跳速。
4. 惯性运动中Pause应立即冻结；Resume不恢复暂停前速度。绿圈结算停止，Replay重新校准并回左侧起点。

保持轻微倾斜、避免一开始就大角度顶到边框。球心顶边时被阻挡不能用来比较滑行距离。当前数值仅为候选，反馈“普通区太滑/太涩、冰面差异太大/太小、刹车过慢/过快”比直接改参数更有用；若报错保留对应日志。

## 参数与日志

满幅输入8192 raw，加速度上限600 px/s²，合成最高速180 px/s（原120），普通/冰面阻尼3.0/0.6 s⁻¹（原4.0/0.8），静止阈值1.5 px/s，无输入低速才置零。app仍10ms物理步、100ms时效/调度门槛、20点校准；这些并非测量级钢珠物理仿真或已冻结手感。

`vel_centi=x,y`是速度乘100后的有符号整数，单位0.01 px/s；`surface=0`普通、`surface=1`冰面。位置仍是地图局部球心整数像素。每约500ms采样日志不代表物理帧率，不能单靠一条速度值证明连续轨迹。
