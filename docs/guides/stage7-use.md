# 第7阶段：黑暗玩法、统一前5与反馈

版本 `0.15.0-dark-feedback`。继续保留冰环迷宫、机关试炼、动力机关、随机挑战四个入口。

## 选择玩法

选关页有两个独立开关：控制“正常/反转”、视野“明亮/黑暗”，可组合为正常、黑暗、反转、黑暗+反转。选择好再进入关卡；本局玩法在开局时固定，回选关可重新选择。本次开机会话内保留设置，重启恢复正常/明亮。

黑暗时只显示小球周围的180×180方形区域，随球和镜头移动，边缘自动裁剪。提示和按钮仍可见；校准、暂停、重玩和复活按原流程操作。随机依然是娱乐模式，没有成绩或排行榜。

## 每关只保存一屏前5

三个固定关分别合并四种玩法排一张榜，最多5条，每条两行显示用时、玩法和本次失误：

1. 用时少者优先，精度为界面显示的0.01秒。
2. 时间相同：黑暗+反转＞反转＞黑暗＞正常。
3. 时间和玩法相同：失误少者优先。
4. 三项相同：已有记录在前，新记录排在同分记录之后。

超过前5的记录直接丢弃，没有隐藏分榜、翻页或额外历史成绩。旧正常/反转各榜升级时也按新规则合并，只保留新前5，保留三关解锁和随机地图身份。

新版兼容读v1至v6，只写356B v7；保存v7后旧固件不能读取。正常升级无需清档或整片擦除。

## 视觉与RGB

过关有绿色边框短亮，失败有两次红色边框短闪，切换菜单/成绩页有下划线展开。反馈期间触摸照常可用，退出或重玩会取消旧反馈，不额外增加成绩用时。

“灯效”默认关；需要时在选关页打开。启用后菜单低亮呼吸，钥匙/开关/检查点及胜败有短提示，游玩常态熄灭。运行中写灯失败会显示“灯效：故障”并关闭本次灯效，可回选关重新尝试，不改变本局游戏状态。板上BAT附近常亮供电指示灯不是这个灯效开关的控制对象。

## 一轮新增短测（TC-081）

1. 检查四入口仍在，旧解锁正常。打开固定关成绩页，确认合并排名、每条玩法标记和完整前5；原数据不足5条时正常留空，不要求为测试再刷5局。
2. 选择黑暗进入已解锁固定关，校准后向四个方向移动并滚动镜头，确认球完整、视野跟随、按钮可用，没有遗留黑块或设备异常。暂停/继续、失败后复活或重玩各试一次即可。
3. 回选关组合黑暗+反转，确认方向与原反转一致；通关或查看已有新记录，确认玩法显示正确。切回明亮后旧玩法正常。
4. 胜败反馈期间直接点重玩/选关，确认无迟到旧反馈；菜单过渡期间可立即点按钮。
5. 可选打开灯效，观察菜单/机关/胜败短提示，再关掉，确认保持熄灭。常亮供电指示灯不用于判断RGB关灯失败。
6. 进入随机黑暗模式，确认仍不记成绩；正常重启后固定前5/解锁与随机地图身份保留。最后在选关页贴一次`free`、`ps`及启动/异常附近日志。

排序的精确同时间/同玩法边界已用主机用例验证，不要求在板上凑出同分。只做本轮新增短测，不恢复旧B/C。主机受控进程中断、离屏和构建不代替真实板端结果。
