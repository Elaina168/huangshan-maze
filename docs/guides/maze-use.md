# 体感迷宫使用说明

当前说明对应0.9.0-progress-save。软件验证及完整构建状态见测试报告；未取得本版板端反馈前，不视为实机验收通过。USB口位于屏幕右侧，正常模式向哪侧压低，小球就向哪侧加速。

## 选关与控制

上电进入选关页，提供“冰岔迷宫”和“冰弯迷宫”。首次存档只开放冰岔迷宫，通关后解锁冰弯迷宫；点击进入准备页，再点击“开始”，放稳板子收集20个稳定样本，正常约1秒。20点是采样数量，不需要点击20次。校准成功后直接开始游玩和计时，3秒内无法满足稳定窗口会提示失败。

选关页可点“控制方向”切换正常/反转。反转同时改变横纵方向，不旋转显示或触摸坐标。进入关卡后固定，标题显示当前模式；重玩、返回及下一关保持选择，重新上电默认正常。正常和反转成绩分别保留本关前5，任一模式通关都可解锁下一关；解锁、累计失误及排行榜保存在板上，重启后保留。

蓝球是玩家，灰墙阻挡，红坑是陷阱，绿色圆为终点，蓝色区域是冰面。倾斜产生加速度，放平后钢珠逐渐减速；反向倾斜先制动再反向。冰面阻尼更小，转弯前需要提前减速。撞墙不失败，球心进入红坑失败、进入终点胜利，结算后停止运动和计时。

## 暂停与返回

- 游玩时点“暂停”，位置和用时冻结；“继续”从原位置恢复，暂停时间不计入。
- 暂停页“校准”保留位置和用时，成功后仍暂停；点击“继续”才恢复。稳定倾斜姿态仍可能成功，失败条件是3秒内一直没有稳定窗口。
- 暂停重校准失败保留旧参考和本轮进度，并保留错误提示；健康采样恢复后可继续，也可重新校准。
- “重玩”清空本轮位置和速度并重新校准当前关卡，不改变方向模式。失败或暂停后重玩继续累计本次挑战用时及失误；通关后重玩才开启新挑战。
- 准备、暂停、结果和错误页的“选关”返回列表，结束本轮并清除旧会话。游玩中先暂停再返回。
- 校准页“取消”返回当前关准备页；若要换关，再点“选关”。

## 过关与下一关

冰岔迷宫过关后有“重玩”“下一关”“选关”。下一关进入已解锁的冰弯迷宫准备页，需要明确点击“开始”重新校准。末关通关提示“全部完成”，提供重玩和选关。失败后可重玩本关或返回选关。

第一关保留既有布局与手感。第二关增加连续转弯及两处冰面转弯区，4个陷阱位于必经通道旁，留有绕行空间。旧简单地图与开放地面对比场已退出产品；历史测试数据仅留开发测试。

## 异常反馈

校准失败可放稳后重试。设备错误冻结本轮，重试校准成功后停在暂停页，明确点“继续”恢复。错误码用于诊断，不算掉坑。

地图载入失败显示原因和实际错误码，可点“选关”重选，不会静默切换其他地图。-2001为格式、-2002为对象定义/数量、-2003为几何位置/大小、-2004为未找到静态安全路线。当前检查是保守格点见证，不是连续空间完备求解。正常游戏不需要串口命令、电脑地图工具或联网。

插电就亮的常绿灯此前已通过照片辨认为供电指示灯，不用它判断RGB是否关闭；本版没有加入新的灯效、音效或振动。

新版短测见[双关检查](level-selection-use.md)。历史个人修改与诊断指南保留为研发过程材料，不是当前游玩入口。

## 成绩与保存

选关页点击“成绩”，可切换关卡及正常/反转模式，查看前5条通关用时、对应失误、累计失误及是否完成。未通关不进入排行榜。排序用时优先，同用时比失误，完全同分时较早记录在前。

“挑战用时”包含同一次挑战中失败重试、暂停重玩前已经游玩的时间，校准、暂停、结果等待及设备错误等待不计时。每次落坑加1失误，校准/设备错误不算失误；通关或返回选关结束本次挑战。

结果或菜单中保存，校准/游玩/暂停时不写Flash。“正在保存”期间请等提示结束；“未保存”表示当前进度暂留RAM，**这时断电可能回到上次已保存的进度**。结果或选关页点“保存”重试，不会重复增加失误或插入成绩。下一次成功提交才清除错误提示。副本待修复表示仍有一份有效档案，可点保存恢复冗余副本。

首次升级0.9.0没有历史档案，第二关重新锁定，之前0.8.0测试不自动转换成成绩。若启动显示“存档不可用”，可重试读取；未知内容/版本不会自动覆盖。首次建库中断而未形成有效档案时，重试不保证修复，不要自行整片擦除。

不保存正在游玩的球位置或校准参考；重新上电从选关开始、方向默认为正常。默认下载只写bootloader/main/ftab，不含存档区；整片擦除或直接擦写游戏区会丢失档案，不能把默认三文件烧录等同于整片恢复出厂。实际板端保存结论以本版重启短测记录为准。

新版新增功能一批检查见[成绩与存档短测](progress-save-use.md)，不重复旧A/B/C。
