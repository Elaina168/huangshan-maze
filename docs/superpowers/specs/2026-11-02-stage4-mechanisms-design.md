# 第4阶段基础机关设计

2026-11-02。用户要求“直接把一个阶段做完”，按brainstorming跳过逐项问答的选择执行整批第4阶段；以下具体规则为实现者裁量，不虚称逐条用户指定。不再等待分项许可；不提交推送、不自动烧录。

## 范围与取舍

粗糙地面、钥匙/开关/门、可破坏墙、检查点复活一起落地。独立对比场与直接修改老图均放弃：前者不是完整正式玩法，后者破坏旧榜可比性。采用新增正式第4关mechanism_trial（机关试炼），前三关源布局/物理/成绩保持，前三任一模式通关第三后解锁第四。第四关串联基础机关，含分岔/绕行、必经通道坑和安全检查点。

不做阶段5磁力/动态障碍、随机生成、黑暗、动画/灯效、看门狗、声音/振动或电脑玩家工具。

## 核心规则

- 新粗糙地面MAZE_SURFACE_ROUGH，字符':'；阻尼候选MAZE_DRAG_ROUGH=9，原normal3/ice0.6、加速度600、限速180、100ms输入/时基限制不变。进出材质不瞬时清速。
- 地图机制独立对象表，最多16项，enum为KEY、SWITCH、KEY_DOOR、SWITCH_DOOR、BREAKABLE、CHECKPOINT；每项maze_rect_t area和unsigned link。钥匙/开关link范围0..7，门引用同类型触发物；钥匙不消耗，触发后门永久打开直到状态重置；开关为接触压下锁存。
- 钥匙/开关/检查点以area中心和半短边定义触发圆，小球扫掠进入该圆的触发范围（加小球半径）即触发，不能高速跳过。关门和破墙为真实矩形碰撞，开门不改原普通墙数据。
- 破墙需法向撞击速度>=100px/s，擦边慢碰不破；破后速度乘0.65保留冲量损耗，墙从碰撞/绘制移除，不能只改画面。普通墙规则不变。
- model中本轮keys/switches/broken为uint32_t；checkpoint=对象index+1，0表示无。检查点激活时保存这些mask，重复停留不覆盖快照；后续不同检查点可替换。
- 落坑仍先LOST并记一次失误。已有检查点时显示“复活”；新MAZE_EVENT_RESPAWN恢复检查点中心与快照，清速度，重开采样代次并校准后游玩；校准/等待不计时。单轮app.elapsed_ms归零，progress已折入此前用时，累计挑战/失误不丢、不重复。
- “重玩”总是回原起点，清全机关和检查点；仍按原挑战累计时间/失误。返回选关结束挑战；取消校准回准备保留原挑战累计；设备错误重试、暂停/重校准保留本轮机关状态。机关快照仅本轮RAM，不做断电续局。
- 判定顺序以最早扫掠碰撞/触发为准，实际进坑不能先吃到坑后的物品；同时间优先危险/碰撞。原三关模型分支行为保持。

## 接口与职责

maze_level.h新增maze_mechanism_kind_t（常量前缀MAZE_MECH_）/maze_mechanism_t {kind,area,link}，level追加mechanisms/mechanism_count。maze_map_definition_t追加同名2字段。maze_model_t追加keys/switches/broken、checkpoint以及checkpoint_keys/checkpoint_switches/checkpoint_broken；新增bool maze_model_respawn(maze_model_t*)。map负责对象边界/引用/触发安全与路线检查；model负责扫掠、碰撞和快照；app负责复活代次/校准；progress负责一次失误与累计时间；UI只读状态绘图。

地图验证沿用原静态几何，并增强支持本阶段锁存机制的可达检查：闭门时先确认触发物可达，再放开对应门；不消耗钥匙，单调状态有界。破墙物理通行由真实模型轨迹补证，不把静态连通当动力学证明。检查点清球/无陷阱/无阻挡复活保证。
