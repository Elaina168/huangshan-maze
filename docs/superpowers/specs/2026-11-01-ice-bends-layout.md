# 第二关：冰弯迷宫布局

用户已查看预览并选择“按此布局接入”，布局获准实施，尚不表示动态/板端验收。

显示名“冰弯迷宫”、稳定ID `ice_bends`，350×300、7×6格，与第一关球半径/墙厚/速度/阻尼相同。42单元连通，41通道形成树，30面内部墙；4个分岔、4条非起终点死路。起点25,25、终点325,275，主路线35段、21次转向。没有绕过挑战的环形捷径，难度主要来自路线长度、连续转弯和冰面制动，主观难度仍需板端体验。

4个半径8px的陷阱位于必经单元29/18/16/12；逐个移除其单元均断开起终点。陷阱偏向通道一侧，留完整球体绕行空间，死路不放坑。单元21/22及25/26为两组冰面转弯区，共4块。
