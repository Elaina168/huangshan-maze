# 第三关“冰环迷宫”布局草案

日期2026-11-02。用户已选择保留原两关、新增正式第三关，当前只审阅布局；本草案尚未进入产品固件或存档。显示名“冰环迷宫”、新ID `ice_loops` 为建议命名，不代表已有接口或用户已单独确认名字。

## 目标与方案

将已总体体验正常的700×600局部视野试验用于真正迷宫；不沿用宽阔的三段折返试验图。保留前两关及其可比成绩；替换第二关会破坏旧成绩的可比性，因此采用独立新关。地图仍固定在固件数据中；设计时对固定布局候选的离线搜索不是板端随机地图功能，也不要求玩家使用电脑工具。

本次不加粗糙地面、钥匙/门、可破坏墙或检查点，不在布局迭代时更改最高速度180px/s、加速度600px/s²、普通/冰面阻尼3.0/0.6s⁻¹。新地面和机关仍按原第4阶段顺序独立定义。

## 布局

- 14×12格、每格50px，总尺寸700×600；墙厚8，球半径7，名义直通通道净宽42。屏幕使用350×300视口，不缩放球/通道。
- 起点25,25；终点675,575，终点半径14，起终点均为终端单元。
- 168单元连通、169通路、141段内部墙；21处分岔、18个非起终点死路，2个独立回环。
- 两处回环均提供普通长路与冰面短路，分别为17段对3段、17段对5段，可各自选择。冰面共6格，分布于两处短路；长路线不必经过冰面。
- 普通参考路线100段、58次方向变化；两处均走冰面时为74段、38次方向变化，中心线少1300px。含绕坑偏移的静态参考线约5016.23/3716.23px，不作为玩家实际通关时间。
- 5个半径8的坑都在起终点必经的直通格，沿参考路线编号1至5。逐一移除相应单元都会断开起终点，死路不承担唯一陷阱挑战。
- 坑向通道一侧偏8px，参考路线向另一侧偏10px，留出整球绕行空间。撞墙只阻挡，球心进入坑才失败，规则沿用原版；不要求球跨坑。

## 预览与验证

[全图预览](../../design/maze-layout-2026-11-02-ice-loops/preview.png)、[两条路线对照](../../design/maze-layout-2026-11-02-ice-loops/routes.png)、[布局JSON](../../design/maze-layout-2026-11-02-ice-loops/layout.json)、[拓扑与静态验证](../../design/maze-layout-2026-11-02-ice-loops/validation.json)。预览虚线仅表示起始视口范围，不是墙，正式游玩不会增加这条虚线或显示答案线。预览使用现有Windows微软雅黑生成，不分发字体文件，不是LVGL或实物截图。

按不超过1px采样检查静态参考折线，完整球到墙/边界最小余量4px，到坑边最小余量3px。逐个坑所在单元的必经性证明保存在validation.json。静态路线检查不能替代真实惯性与板端测试。

另用临时设计夹具调用现有真实C装载器和惯性模型，验证该数据可装载、两条输入轨迹通关、五坑分别滚入失败并冻结；不修改产品源码，不将夹具接入产品。见[原始设计验证](../../../evidence/design/2026-11-02-ice-loops-01/README.md)。模型采用保守停靠参考点，不将模型毫秒写作人工通关耗时。

## 正式接入前必须处理的事项

当前正式目录只有两关、旧档为353字节/两关固定格式，尚未实现第三关或兼容升级。布局确认后，正式接入设计需覆盖选关页第三入口/下一关/解锁、老档原成绩及解锁保留、第三关按第二关完成情况开放，并拒绝未知版本，不能清档代替升级。

0.9.3试验静态绘图缓冲已占234000B，ARM未分配尾区119092B不是运行可用堆。第三关由35段试验墙增加至141段墙，LVGL对象、绘图成本和正式存档运行内存必须重新预算/验证，必要的可见对象管理由实际数据决定；此前“没问题”不覆盖新增地图或存档升级。

本轮只请求布局选择：是否接受此图的路线、两个冰面选择和五个必经通道陷阱。没有产品源码改动、SDK构建/自动烧录或提交推送。

用户随后确认“可以”，本布局已批准。正式三关接入/旧存档升级仍须按[正式设计](2026-11-02-third-level-design.md)审阅，不将布局认可扩展为存档格式或产品实现已经通过。
