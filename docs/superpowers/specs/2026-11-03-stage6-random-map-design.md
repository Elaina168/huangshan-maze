# 第6阶段板端随机地图设计

2026-11-03。状态：方向已获用户选择，具体设计待审阅，未实现。用户选择“随机迷宫骨架＋已验证机关模板”，并接受此前提案中的重玩保留当前图、另有换图和成绩隔离方向。下列规模、算法、参数、存档与细则为Codex提案，不虚称逐项用户指定。原0.12.1第五关修复已获用户总体正常反馈，缺少量化项目仍待证。

## 目标与取舍

在板上点击即可生成新的可玩迷宫，无电脑工具、串口指令、文件导入或网络依赖。保留固定五关、原成绩/解锁和180/600物理参数、100ms保护、显示完成等待与350×300跟随视口。

采用随机拓扑与受限机关模板；放弃仅换几张固定图的假随机，也不承诺任意机关随机摆放可解。另一可行方案为先纯迷宫、以后再接机关，用户已选择本方案。不提前做黑暗、动画灯效、看门狗、声音/振动、传送门、弹跳板或持久校准。

## 板上流程

选关页增加独立“随机挑战”入口，初始可用，不要求先通第五关；它不是固定第六关，不参与固定关卡解锁链。五个固定入口、成绩/方向配置继续可触摸，无拥挤重叠；实际排版在UI离屏预览中验证，必要用滚动列表。

进入随机准备页：显示种子、正常/反转模式、开始、换一张、返回；第一次尚无地图时自动开始生成。生成时显示阶段/进度和取消，完成才发布新地图。失败明确显示原因及重试/返回，不能把未校验图交给模型或悄悄装旧图冒充成功。

“重玩”复用当前布局/种子并复位机关、重新校准，挑战累计时间/失误沿用既有规则；“换一张”只在准备/暂停/结果状态提供，先生成候选；成功接受新图时才结束当前挑战并清除旧随机榜。按钮文案须写明“换图并重置本图成绩”，不用隐藏的自动清榜。游玩中先暂停才能换图。返回结束本次挑战但保留当前图及其成绩；重启重建同一图，不恢复球位置、机关局内状态或检查点。

正常/反转共享同一地图，成绩分别保存。方向设置仍在选关页修改，不在关内改变。

## 生成范围与模板契约

生成器版本1，基础规模为6×5个100px宏格，落到当前12×10个50px字符串格、世界600×500，不扩大MAZE_MAP_MAX_COLUMNS=14/MAX_ROWS=12等容量。每个宏格内部清空，边界通过现有8px墙和固定门户连接，球半径7px；不得靠重叠墙形成窄于整球的通道。

固定容量栈执行随机DFS生成覆盖宏格的树形拓扑。选边界起点，用树上最远节点作为终点，回溯获得唯一主路径；主路径至少10个宏格，保留至少3个分岔与死路，防止只生成宽直通道。达不到约束则候选失败，不补造成功。树形结构确保主路切点不能从其他分支绕过；随机改变树、起终点、材质与模板选择，不仅随机颜色。

模板独立定义入口/出口方向、占用宏格、实体区域、触发区域、影响包络和安全等候/出入口；只允许旋转90度倍数和受支持的镜像。入口出口球心与速度限制构成开发期动力学见证的前置条件。普通连接区能停球并重新对准；模板间不直接相互施力或移动挤压。

第一版支持普通/冰/粗糙、可绕避陷阱、检查点、钥匙/锁存开关门、磁场、激光、定时闸门及巡逻块的已验证模板。可破坏墙继续保留固定关玩法，本轮不随机布置：足速正撞的起跑距离尚无一般生成规则，避免只凭BFS认定可破。

- 主路径安排至少一个地形变化、至少两种复杂模板；复杂模板优先放在度为2的直行宏格，避免侧门户绕过危险或不小心把门封在转弯位置。每张图不必包含全部机关种类。
- 陷阱放在必经通道中，留出整球绕避的安全路径，不用完全封路或仅藏死路的方法凑难度。检查点设在危险前的安全格，原相位快照规则保持。
- 钥匙/开关放在对应门之前已可达的主路或可回到主路的支路，门只引用已有唯一触发物；先做单调状态可达检查，不能把钥匙放在自己的门后。最多两组触发门，总基础机关仍不超过16。
- 磁场模板外半径35、内半径12、峰值不超过240，包络含球半径与门户余量，避免影响相邻格；固定第五关的70半径不变。
- 激光/闸门沿用第五关周期和提示；巡逻沿用35px/s、端点停400ms，扫掠区与固定墙/门、另一巡逻、检查点和安全门户不交叠，保留绕行空间。最多4个动态对象，低于现有8上限。
- 冰面不能覆盖模板的制动/等候安全区；模板实体/磁场影响包络之间不得交叠。已有map几何检查的球半径裕量仍适用。

## 可玩性与校验层次

1. 数据：字符串格式、有限数值、对象容量、链接/相位与包络约束，拒绝非法数据。
2. 几何/状态：实际球半径的安全连通、陷阱绕行、各触发物先可达、必经模板无支路绕过，检查点及门户可安全停车。
3. 动力学：每个支持模板在开发时用真实模型输入完成进入、制动、等待/通过、离开，覆盖方向变换与允许的到达相位；模板接口只在这些已验证条件内组合。固定种子整图还需真实模型逐路径通关，不能只测BFS。

板上采用前两层与已认证模板契约，不在运行时穷举所有控制轨迹。开发期有限种子/相位覆盖不是所有32位种子的数学证明；受支持构造、边界检查、失败明确拒绝共同限定保证范围。没有完成认证的模板不得随机启用，不以校验失败时删掉机关伪装同一候选通过。

## 种子、预算与生命周期

使用项目自有确定性32位PRNG，不依赖libc rand或联网。首次公开种子取进入时板端tick混合固定常量（不宣称密码学随机）；已有图的换图从旧种子推进确定性序列。生成器版本＋接受的实际种子＋固定规则确定全部布局/机关；重启与重玩不得读取当前tick改变布局。种子为0也须有确定语义，不能当未初始化标志。

单次生成最多尝试8个候选，实际通过的候选种子才成为当前图；相同公开种子重建只重建该候选并校验，不能偷偷跳种子。候选失败可推进下一种子；预算耗尽显示生成失败，不进行无界while重试。

生成分为拓扑、模板装配、格式/几何、路线检查、发布；候选和活动地图使用两个静态、稳定地址的完整地图/定义缓冲；字符串、基础/动态对象表与所属地图同寿命。现有maze_map_t含自指针，不得按值拷贝候选到nav.map；发布时切换活动地图指针，后续装载只覆写无引用的非活动缓冲。取消/失败保留原已接受种子、成绩及挑战状态，恢复原准备/暂停/结果页，不重新结算用时或失误；没有旧图则回随机入口错误页。新图通过后才解除旧场景引用、结束旧挑战、增加采样/页面代次并原子替换；迟到采样或取消后的完成结果不得影响新页面。生成请求有独立任务标识，不能为了取消候选就重置旧挑战。若旧挑战为暂停态，生成期间保持该暂停会话的IMU生产/健康采样但不推进物理或机关；取消后保留参考和暂停态，避免停掉生产后误用同代次重启被handled_generation忽略。接受新图再正常取消旧会话并以新代次校准。

在未游玩状态分片执行，每轮最多128个路线节点，并在每条邻边及墙/坑/机关扫描内部保存可续作游标；每片最多1024次基本几何检查且有10ms墙钟截止，任何一项预算先到即让出。不能把一个节点内遍历全部对象视为一次廉价操作。轮间回到主循环处理UI；不在LVGL绘图/flush回调内执行生成、地图验证或存档。现有同步map_load需复用/提取校验阶段为可续作的工作区，固定五关语义不变，不另写弱校验器。实际每片耗时目标<=10ms、整次生成总目标<=3s；实现后以目标板测量确认，超时取消并明确失败，不放宽现有控制100ms限制。增量工作区必须静态或明确受控，复核主栈和RAM，不能新建整图像缓冲。

## 成绩与持久化

固定五关排行榜保持；随机只保存“当前种子”的正常/反转各前5成绩和累计失误。不同种子或生成器版本不混排，也不提供跨随机图的总时间榜。换图成功才清旧随机成绩，取消、失败或重复进入不清榜。种子与成绩同一档案事务提交，不能出现新种子搭配旧成绩。

继续同一A/B、32KiB每bank和8KiB扇区，不清档。候选v5固定982B：保持21B头、固定五关820B记录，CRC前追加137B随机块（valid1B、generator_version2B、seed4B、正常/反转各65B，含losses4/count1/5项12B成绩），最后CRC4B；即21+820+137+4=982。头的固定关卡计数仍5，随机块不冒充第六固定记录，rules仍1。旧v1/v2/v3/v4兼容读，随机块默认valid=0/其余全0，新版只写v5。

valid=1才重建当前图。已知v5布局中的generator_version只作结构读取；当前生成器仅支持版本1。未知生成器版本或无法重建的已存图在随机页显式报错，不自动重置或用新算法生成“同种子不同图”。已知布局的随机字段与成绩保持原样，返回固定关游玩/保存时仍原样编码该随机块，不擅自归零；只有玩家显式点击“换图并重置本图成绩”并成功接受新图时才替换为当前生成器版本。未知档案格式/规则仍沿用现有全档保护，不因能读到一个种子就允许覆盖。valid=0时随机块其余字段必须全0，已知版本重建失败不自动换种子。

首次/换图接受后在准备/菜单安全状态保存一次；保存失败有未保存提示和同修订重试，允许明确标识的RAM游玩，重启可能恢复上次成功种子与成绩。重玩/重建不增加修订，通关/失误仍按既有一次结算规则。迁移只递增一次，混合快照/最高修订保护与原样旧字段保持。真实SDK库需验证982B记录、GC及迁移受控中断，不能把主机模型当物理掉电测试。
