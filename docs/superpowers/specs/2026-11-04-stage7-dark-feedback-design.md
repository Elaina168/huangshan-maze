# 第7阶段：四种玩法、统一可见榜单与视觉反馈

用户已明确：黑暗和反转同级，可自由组合；固定关排行榜按用时升序，同时间黑暗+反转＞反转＞黑暗＞正常，同时间同玩法失误少者优先，完全相同已有记录在前。每关只保存屏幕完整显示的前5条，多余直接丢弃。当前三个固定关＋随机娱乐四入口继续；随机不入榜。

## 行为与数据

- 选关页提供方向、视野两个独立开关，均为本次开机会话设置，默认正常/明亮；进入关卡时冻结到app。和原反转一致，只在选关页切换，避免一局中途改变玩法导致成绩不可比。
- 模式值0正常、1黑暗、2反转、3黑暗+反转。物理输入只由反转位控制；黑暗仅限制显示，完整碰撞/机关时钟/校准不变。三固定关与随机都支持四组合。
- 固定每关一张榜、最多5条，成绩含time_cs、mistakes、mode。统一稳定比较器供插入、迁移及解码排序检查使用；第6名不留隐藏槽、不提供滚动/翻页。每条两行，五条从y124起每44px完整显示到340；下方切关/返回不遮挡。
- 保留关卡总失误和四位通关标记，任意玩法完成即可解锁下一关。原正常/反转通关标记映射位0/位2；旧各榜最多10条合并后只留新前5，其余按用户要求丢弃。原随机身份继续保存，娱乐胜败不记分。
- 只写v7共356B：头21B＋3×108B关记录＋随机身份7B＋CRC4B。关记录=ID32/unlocked1/completed1/总失误8/count1/5×(time8/mistakes4/mode1)。兼容读v1至v6，最大旧长度982B，未知版本/规则保持保护；A/B各32KiB/8KiB扇区及原下载地址不变。旧字段没有可显示意义的未使用成绩槽不迁移。

## 显示与灯效

- 黑暗采用以小球为中心、半径90px的方形视窗。四块不透明深色矩形只覆盖现有350×300视口的视窗外部分；边缘裁剪，世界与球仍使用原场景，不增加整图或透明全屏缓存。遮挡位于球上方、提示面板下方，HUD与触摸按钮保持可读。暂停/校准/复活不泄漏远处地图。
- 过关以绿色边框短亮400ms、失败以红色边框两次短闪480ms反馈；不改变球位置，不延迟计时/结算/触摸。菜单/成绩页用150ms标题下划线展开表示过渡，避免整屏淡入引发大图层重绘。
- RGB灯效是独立可选开关，默认关闭，尊重此前关灯需求。启用后菜单低亮呼吸、拾取/开关/检查点短提示、胜败对应短色；游玩常态熄灭。常规更新每50ms最多输出一次且颜色变化才写，主动关闭灯效可立即熄灭一次；只在外层主循环调驱动，flush协作服务不执行灯效I/O。设备错误明确记录，关掉本次灯效并在设置中显示错误，游戏状态不被灯效改写。
- 显示动画由基于tick的纯反馈状态驱动，取消/切页/新采样代次作废旧反馈；存档保存引起的同页page_version刷新不重放胜败。保持原单缓冲逐笔真实完成等待、100ms保护和1ms物理子片。
