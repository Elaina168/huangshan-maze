## 主要问题与修复

1. 初始屏幕方向与早期IMU测试方向相反：按USB在右侧统一映射，保留误摆姿态/重测原始证据。
2. 显示服务阻塞引发-1002/-1004：将显示完成期间的纯逻辑服务与外层I/O分开，保持100ms保护；不以简单延长阈值掩盖问题。
3. 滚动时球闪烁、地图留下黑块：核对实际LCD异步完成，单视口缓冲等待屏障、合并球区域并统一遮挡刷新；历史修复反馈和最终离屏回归分别保留。
4. 看成绩返回路径、随机保存失败反馈、RGB节流曾有缺陷：增加针对性失败用例、修复并保留RED/GREEN与后续回归。
5. 最后一轮删除冗余文字：先由真实LVGL断言重现旧标题，再精简对象/缓存/计数与字体，当前三固定关/随机/成绩回归通过。

## 未确认与限制

用户总体接受没有附完整逐项操作日志、设备固件哈希核验、最终free/ps或计时测量。TC-081/085等量化子项不因封版选择自动补判通过。看门狗硬件故障注入/实物复位时间、真实物理掉电、长时老化、严格响应延迟/帧率/温漂、教师正式验收均未获得独立完整证据。

软件WDT正常窗口为5秒，但中断链也失效时依赖芯片二段复位，不能承诺所有故障5秒恢复；原有采样错误页仍人工重试。BAT常亮供电指示灯不等于RGB灯效故障。静态内存不替代运行时堆栈测量。

上述限制随最终材料交付，不伪造通过，不恢复用户已停止的旧B/C批次。后续仅在发现具体问题时修复并追加真实回归记录。
