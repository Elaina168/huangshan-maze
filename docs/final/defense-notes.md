# 答辩与个人能力准备提纲

李天宇，2024211450。本提纲用于组织现场演示、代码讲解和个人操作。

## 建议实物演示顺序

先说明产品用途和板上独立操作，再演示选关/开始校准/倾斜惯性/墙陷阱或机关/检查点复活/暂停继续/结果保存与成绩。随后展示黑暗+反转或随机挑战，介绍固定关成绩与随机娱乐的定位。演示时长按教师安排，准备板卡、数据线、固件和工程。

异常恢复环节可展示校准提示、错误记录和重试流程；专项恢复实验按测试报告中的计划执行。视频可用于辅助展示，核心操作在实物上完成。

## 代码讲解要点

1. main.c main：初始化、采样/导航/结算/存储/显示、完整轮次WDT完成点；为什么flush期间只能做受限服务。
2. maze_imu.c后台任务：I2C读数、请求代次、序号与快照；maze_app_sample怎样拒绝旧/重复/过期采样。
3. maze_app_event与maze_app_update：校准、暂停/恢复、胜败、重新校准和错误页；暂停期间的计时管理。
4. maze_model：输入变加速度，速度累计、阻力、限速与碰撞；为什么放平后继续滑、冰面更滑。
5. maze_ui：世界坐标到镜头/屏幕、单缓冲实际提交完成、新旧球区域合并及黑暗遮挡；渲染耗时与LCD传输完成状态的联合诊断。
6. maze_progress/maze_score_insert：前5真实容量，时间→玩法→失误→稳定同分；随机模式采用独立娱乐流程。
7. maze_archive/maze_store：v7旧档迁移、A/B保护、错误处理；受控中断与真实断电的区别。
8. maze_watchdog：删除SDK idle自动喂狗，完整主循环才喂；活跃错误页与卡死复位的处理分工。

## 本人操作准备

个人操作流程：定位一个参数或UI文案，解释其影响范围，完成修改、构建、下载和验证，并展示对应提交与日志。结合RGB练习和迷宫迭代记录，讲解从代码入口到板端行为的完整路径。
