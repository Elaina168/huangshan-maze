# 产品需求规格（最终范围）

李天宇，2024211450。程序0.16.1-ui-trim；需求变更原文与编号见[历史需求](../product-requirements.md)。当前范围优先于其中早期单关、五关、随机排行榜等历史描述。

## 产品与闭环

在黄山派上离线运行的掌上体感迷宫。USB供电，屏幕正常方向为USB在右侧；倾斜控制钢珠加速、反向制动，触摸完成选关、开始校准、暂停/继续、重玩/复活和返回。大地图由镜头显示球周围的一部分，无电脑端运行依赖。

首次开始须放稳约1秒完成20点稳定窗口校准；校准超时可重试，不能边持续晃动边假定零点有效。触发失败后按现有检查点复活或重玩；暂停期间不推进运动时间，重校准/错误恢复后回暂停再继续。仅已保存成绩/解锁/地图身份重启保留，旧速度与校准会话不恢复。

## 参数与验收解释

参数集中在src/maze_config.h：限速180、最大加速度600、三种阻力3.0/0.6/9.0、20点/950ms跨度/300raw范围/3000ms预算校准、300raw死区、100ms输入有效期。这些是软件配置和候选手感参数，不是实测的响应延迟或稳定性结论。

必达闭环由软件断言、历次板端反馈和本次最终选择支持；逐项证据和未测性能见[测试报告](test-report.md)。教师立项/验收审批、严格性能/长时/物理掉电和看门狗实物复位时延没有被本次用户确认自动替代。
