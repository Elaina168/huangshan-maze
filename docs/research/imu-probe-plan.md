# IMU 四向映射预研实施记录

对应 C-11/C-18/C-19/C-24，支持后续 REQ-002/003/011；这是诊断预研，不实现迷宫功能，不确定正式校准/死区参数。

用户在已说明“四向映射预研”的下一步后要求继续。问题是屏幕朝向固定时，各姿态相对中立的加速度轴与符号如何变化。采用最小串口探针：msh命令 `imu_probe neutral|right|left|up|down`，每次40点、样本间等待50ms。姿态标签只是用户记录，不自动识别姿态。

数据路径：串口命令→msh线程→i2c3→ID核对→保存控制寄存器→启用104Hz/±2g加速度→有截止的就绪检查→读三轴→原始记录与统计→恢复配置→命令返回。只有此诊断命令访问IMU；不调用LVGL、不创建长期任务。底层I2C默认超时5000ms来自drv_i2c.c，200ms就绪期限不意味着阻塞I2C能被200ms中断。故障会结束取样并尝试恢复，保留采样和恢复两种错误。

文件：新增 `src/imu_probe.c` 为诊断命令，`tests/imu_probe/` 提供真实源码的主机故障注入，`scripts/test_imu_probe.py` 编译运行主机测试；project/proj.conf增加实际SDK的I2C3配置。main.c中的本人RGB修改保留。来源清单标记修改的配置，具体复用方法记入THIRD_PARTY。
